## Contracts verified rather than re-implemented

Nesting-depth enforcement (contract **J**,
[#16668](https://github.com/stablyai/orca/pull/16668)), durable dispatch
idempotency and journal recovery
([#16904](https://github.com/stablyai/orca/pull/16904)), and the headless
recovery sweep were already closed upstream before this Odin increment
started. Odin added no code for these — it ran the existing tests that pin
them and cites where they live, so a future change in this worktree cannot
regress them without a visible test failure. Full detail:
[`odin/VERIFIED.md`](https://github.com/unempyd/odin/blob/main/odin/VERIFIED.md).
