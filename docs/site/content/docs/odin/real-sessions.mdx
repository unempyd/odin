Unit tests prove a function's contract. They don't prove that a real agent
CLI, launched by the real orchestration code, on a real headless host,
actually behaves the way the contract says. `odin/proof/real-sessions.mjs`
does that: it drives real `claude`, `codex`, and `grok` CLIs through Orca's
own `orchestration worker-start` on a headless `serve` host with an isolated
profile, and records the run.

## Two things a unit test can't show

**The [H](/docs/odin/residuals) contract acting on a real profile.** The same
artifact that shows a settled Claude/Codex run also shows a Codex worker parked
on its approval prompt when the profile's grants were written without
`agentBypassDefaultsReviewed`
(`real-sessions.2026-09-14T15-05-30-764Z.json`, kept as evidence).

**The operator's own agent configuration is outside Odin's contract.** The
Claude worker completes even in the safe-default phase because this
operator's Claude config auto-approves; the argv still carries no flag from
Odin. Odin controls what Orca launches with — it does not, and cannot,
control what an agent's own configuration decides once it is running.

## Linux and SSH

Every manifest proof reproduces at upstream and closes on Odin inside a
`node:24-bookworm` container, and the twelve process-ownership test files that
read a real `ps` and `/proc` pass there; the run is re-derivable with the
checked-in `odin/proof/run-proofs-linux.sh`, which writes
`odin/proofs/linux-proofs.<sha>.txt`.

`odin/proof/ssh-boundary.mjs` drives a real desktop-mode host against a real
VPS: SSH target and repo registration surfaced through the real RPC, an
`ssh.connect` relay deploy reaching `connected`, and a loss-of-contact matrix
(transport drop, relay `SIGKILL`, reconnect re-adoption, owner-proven exit)
whose strengthened form requires the client to actually observe the loss, no
sample to claim an exit, and `terminal wait --for exit` to resolve during the
outage. The first strengthened run failed that row and exposed the
**show-contact-loss** residual; the run after the fix passes it. Full diagnosis:
`odin/proofs/ssh-boundary.md`.
